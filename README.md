# Projeto ETL AdventureWorks - Data Warehouse

## Descrição
Projeto desenvolvido como atividade prática de Business Intelligence (BI), abordando conceitos de ETL, modelagem multidimensional e storytelling com dados.

## Tecnologias
- Python (pandas, psycopg2)
- PostgreSQL
- Power BI / Metabase (para visualização dos indicadores)

## Estrutura do Projeto
- `etl_adventureworks.py`: script de ETL
- `modelagem_dw.sql`: criação das tabelas fato e dimensão
- `indicadores.sql`: consultas SQL dos 10 KPIs
- `artigo_unisales.docx`: artigo no formato acadêmico
